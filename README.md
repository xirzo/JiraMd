Browser extension for bidirectional conversion between Jira Markdown and standard Markdown.

## Installation

### Chrome / Edge / Brave

1. Download or clone this repository:
   ```bash
   git clone https://github.com/xirzo/JiraMd.git
   cd jiraMd
   ```

2. Open your browser and navigate to:
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Brave**: `brave://extensions/`

3. Enable **Developer mode** (toggle in the top right corner)

4. Click **Load unpacked**

5. Select the `JiraMd` directory

6. The extension icon should appear in your browser toolbar

### Firefox

1. Download or clone this repository:
   ```bash
   git clone https://github.com/xirzo/JiraMd.git
   cd JiraMd
   ```

2. Open Firefox and navigate to: `about:debugging`

3. Click **Load Temporary Add-on**

4. Navigate to the `JiraMd` directory and select any file

5. The extension will be loaded temporarily (until browser restart)
